Function overloads that differ only by a single parameter type or by optional parameters
can be simplified using union types or optional parameters.

## Examples

### Union Types

<Tabs>
<TabItem label="❌ Incorrect">

```ts
interface Parser {
	parse(input: string): Document;
	parse(input: Buffer): Document;
}
```

</TabItem>
<TabItem label="✅ Correct">

```ts
interface Parser {
	parse(input: string | Buffer): Document;
}
```

</TabItem>
</Tabs>

### Optional Parameters

<Tabs>
<TabItem label="❌ Incorrect">

```ts
interface Logger {
	log(): void;
	log(message: string): void;
}
```

</TabItem>
<TabItem label="✅ Correct">

```ts
interface Logger {
	log(message?: string): void;
}
```

</TabItem>
</Tabs>

## Options

This rule is not configurable.

## When Not To Use It

If you intentionally use separate overloads for different behaviors or documentation purposes,
you may want to disable this rule.
