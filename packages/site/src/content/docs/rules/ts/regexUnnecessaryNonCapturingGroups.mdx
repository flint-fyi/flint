Reports non-capturing groups `(?:...)` that serve no purpose and can be removed without changing the meaning of the regex.

## Examples

### Single Element Without Quantifier

<Tabs>
<TabItem label="❌ Incorrect">

```ts
const pattern = /(?:abcd)/;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
const pattern = /abcd/;
```

</TabItem>
</Tabs>

### Single Element With Quantifier

<Tabs>
<TabItem label="❌ Incorrect">

```ts
const pattern = /(?:a)+/;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
const pattern = /a+/;
```

</TabItem>
</Tabs>

### Top-Level Alternation Wrapper

<Tabs>
<TabItem label="❌ Incorrect">

```ts
const pattern = /(?:a|b)/;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
const pattern = /a|b/;
```

</TabItem>
</Tabs>

### Necessary Groups

Groups are necessary when:

- They apply a quantifier to multiple elements: `/(?:ab)+/`
- They group alternations that are not the only element: `/a(?:b|c)d/`
- Removing them would create escape sequences: `/\x4(?:1)/`
- They wrap a quantified element for an outer quantifier: `/(?:a{2})+/`

```ts
// All of these are valid - the groups are necessary
const multiElement = /(?:ab)+/;
const alternationInContext = /a(?:b|c)d/;
const escapeHazard = /\x4(?:1)/;
const nestedQuantifier = /(?:a{2})+/;
```

## Options

This rule is not configurable.

## When Not To Use It

If you prefer to keep non-capturing groups for readability or organizational purposes, you might want to disable this rule.
