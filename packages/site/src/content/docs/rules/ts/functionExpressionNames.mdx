Named function expressions produce better stack traces for debugging.
The function name appears in error messages and developer tools, making it easier to identify the source of issues.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```ts
array.map(function (item) {
	return item;
});
```

```ts
(function () {})();
```

</TabItem>
<TabItem label="✅ Correct">

```ts
array.map(function identity(item) {
	return item;
});
```

```ts
(function main() {})();
```

</TabItem>
</Tabs>

## Options

This rule is not configurable.

## When Not To Use It

If you prefer trimming to minimal amounts of code and don't mind anonymous functions in your call stacks, this rule might not be for you.
