Triple-slash reference directives must use valid directive types and proper formatting.
Only `path`, `types`, `lib`, and `no-default-lib` are valid directive attributes.

## Examples

### Invalid Directive Type

<Tabs>
<TabItem label="❌ Incorrect">

```ts
/// <reference foo="bar" />
export const value = 1;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
/// <reference types="node" />
export const value = 1;
```

</TabItem>
</Tabs>

### Missing Attribute Value

<Tabs>
<TabItem label="❌ Incorrect">

```ts
/// <reference types />
export const value = 1;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
/// <reference types="node" />
export const value = 1;
```

</TabItem>
</Tabs>

## Options

This rule is not configurable.

## When Not To Use It

This rule should always be enabled to catch malformed triple-slash reference directives.
