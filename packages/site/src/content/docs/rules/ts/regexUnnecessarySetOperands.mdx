Regular expressions with the `v` flag support character class set operations like intersection (`&&`) and subtraction (`--`).
This rule identifies operands in these operations that are unnecessary or produce unexpected results.

The rule detects four types of issues:

1. **Disjoint intersection**: Two sets with no common elements intersected together, producing an empty result
2. **Subset intersection**: A superset operand in an intersection that is redundant
3. **Disjoint subtraction**: Subtracting a set that shares no elements, which has no effect
4. **Subset subtraction**: Subtracting a superset, which produces an empty result

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```ts
// Disjoint intersection - \w and \s have no common elements
const pattern = /[\w&&\s]/v;
```

```ts
// Subset intersection - \w is a superset of \d, so \w is redundant
const pattern = /[\w&&\d]/v;
```

```ts
// Disjoint subtraction - \s has no overlap with \w, subtraction does nothing
const pattern = /[\w--\s]/v;
```

```ts
// Subset subtraction - \w contains all of \d, result is empty
const pattern = /[\d--\w]/v;
```

```ts
// Disjoint intersection with character classes
const pattern = /[[abc]&&[def]]/v;
```

</TabItem>
<TabItem label="✅ Correct">

```ts
// Valid subtraction - removes digits from word characters
const pattern = /[\w--\d]/v;
```

```ts
// Valid intersection - finds common elements
const pattern = /[[a-z]&&[a-m]]/v;
```

```ts
// Valid subtraction - removes vowels from letters
const pattern = /[[a-z]--[aeiou]]/v;
```

```ts
// Without v flag, set operations are not supported
const pattern = /[\w&&\s]/;
```

```ts
// Simple character class without set operations
const pattern = /[\w\d]/v;
```

</TabItem>
</Tabs>

## Options

This rule is not configurable.

## When Not To Use It

If you intentionally use set operations that produce empty results for documentation or testing purposes, you may want to disable this rule.
