<RuleSummary plugin="package-json" rule="workspacesValidity" />

This rule checks that the `workspaces` property is an array of non-empty strings.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{
	"workspaces": "./packages/*"
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"workspaces": ["./app", "./packages/*"]
}
```

</TabItem>
</Tabs>

## When Not To Use It

If you don't use workspaces in your project, you can disable this rule.
