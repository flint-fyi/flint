npm requires that the `author` field in `package.json` is present.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
</Tabs>

## When Not To Use It

If your package doesn't need to specify a name, you can disable this rule.
For example, if your package is local-only and is never published online or made open source, naming may not be relevant for you.
