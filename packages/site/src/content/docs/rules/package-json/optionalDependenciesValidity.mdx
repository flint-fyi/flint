<RuleSummary plugin="package-json" rule="optionalDependenciesValidity" />

The rule checks that, if present, the `optionalDependencies` property is an object where each key is a valid package name and each value is a valid version range.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{
	"optionalDependencies": {
		"invalid-version": "catalob:"
	}
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"optionalDependencies": {
		"nin": "catalog:",
		"thee-silver-mt-zion": "^1.2.3",
		"david-bowie": "*"
	}
}
```

</TabItem>
</Tabs>

## When Not To Use It

If you don't validate dependency versions in your projects, you can disable this rule.
