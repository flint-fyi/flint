<RuleSummary plugin="package-json" rule="binPresence" />

npm requires that the `bin` field in `package.json` is present.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"bin": "./lib/index.js"
}
```

```json
{
	"bin": "./lib/index.js",
	"name": "my-repository"
}
```

</TabItem>
</Tabs>

## When Not To Use It

If your package doesn't need to specify a `bin`, you can disable this rule.
