npm requires that the `author` field in `package.json` follows certain specifications if it is present.
The field can be either a string or an object with specific properties.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{
	"author": ""
}
```

```json
{
	"author": null
}
```

```json
{
	"author": "John <invalid>"
}
```

```json
{
	"author": {}
}
```

```json
{
	"author": {
		"name": "John",
		"email": "invalid"
	}
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"author": "John Doe"
}
```

```json
{
	"author": "John <john@example.com>"
}
```

```json
{
	"author": {
		"name": "John"
	}
}
```

```json
{
	"author": {
		"name": "John",
		"email": "john@example.com",
		"url": "https://example.com"
	}
}
```

</TabItem>
</Tabs>

## When Not To Use It

If you don't care about strict compliance with npm's author field specification, you can disable this rule.
