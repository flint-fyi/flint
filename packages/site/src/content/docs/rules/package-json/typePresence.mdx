<RuleSummary plugin="package-json" rule="typePresence" />

npm requires that the `type` field in `package.json` is present.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
</Tabs>

## When Not To Use It

If your package doesn't need to specify a `type`, you can disable this rule.
