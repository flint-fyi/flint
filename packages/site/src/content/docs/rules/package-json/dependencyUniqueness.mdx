This rule reports dependency names that are repeated in the same `package.json` dependency collection.
For consistency with `eslint-plugin-package-json`, it also reports dependency names that appear in `devDependencies` or `peerDependencies` when they are already declared in `dependencies`.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{
	"dependencies": {
		"left-pad": "^1.3.0",
		"left-pad": "^1.3.0"
	}
}
```

```json
{
	"dependencies": {
		"left-pad": "^1.3.0"
	},
	"devDependencies": {
		"left-pad": "^1.3.0"
	}
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"dependencies": {
		"left-pad": "^1.3.0"
	},
	"devDependencies": {
		"vitest": "^4.0.0"
	}
}
```

</TabItem>
</Tabs>

## When Not To Use It

If your package intentionally repeats dependency names across dependency collections, such as to mirror a runtime dependency into `peerDependencies`, you can disable this rule.
