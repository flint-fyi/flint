<RuleSummary plugin="package-json" rule="peerDependenciesPresence" />

npm requires that the `peerDependencies` field in `package.json` is present.

## Examples

<Tabs>
<TabItem label="❌ Incorrect">

```json
{}
```

```json
{
	"name": "my-repository"
}
```

</TabItem>
<TabItem label="✅ Correct">

```json
{
	"peerDependencies": {}
}
```

```json
{
	"name": "my-repository",
	"peerDependencies": {}
}
```

</TabItem>
</Tabs>

## When Not To Use It

If your package doesn't need to specify `peerDependencies`, you can disable this rule.
