Flint plugins document each `*Strict` preset, such as `logicalStrict`, as a superset of its base preset, such as `logical`.
Plugins build presets from each rule's `about.presets` list, so a rule listed in `logical` but not `logicalStrict` is silently left out of the strict preset.
Users who enable only `logicalStrict` then do not receive that rule.

This rule reports a preset in a rule's `about.presets` when the rule's `RuleCreator` declares a matching `*Strict` preset that the rule does not list.
It provides a suggestion to add the missing `*Strict` preset.

import { RuleCreator } from "@flint.fyi/core";

	docs: (ruleId) => `https://example.com/rules/${ruleId}`,
	pluginId: "example",
	presets: ["logical", "logicalStrict"],

	about: {
		description: "Example rule.",
		id: "example",

## Options

This rule is not configurable.

## When Not To Use It

If your plugin's `*Strict` presets are intentionally not supersets of their base presets, such as a strict preset that replaces a rule with a stricter alternative, this rule will report rules you deliberately left out.
You may prefer to disable this rule for those rules with a disable comment.
